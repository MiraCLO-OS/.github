## About

**MiraCLO** (from the Latin *mira*, "wonder", and **CLO**, CodeLinaro) is a custom Android ROM built on Qualcomm's CodeLinaro platform sources through Paranoid Android (AOSPA) Calcite.

Its aim is simple: the stability and efficiency of a CLO base, with a calm, polished interface that feels premium without getting in the way.

- **Pure CLO underneath:** Qualcomm CodeLinaro frameworks, HALs and performance stack
- **Refined, not crowded:** a small set of considered features instead of a long list of toggles
- **Signed builds:** every release is signed with MiraCLO's own release keys

## Highlights

- MiraCLO boot animation, wallpapers (*Nero* and *Carrara*) and branding
- **MiraCLO version** shown in Settings › About phone
- Quick Settings with perfectly circular icon tiles
- Qualcomm (CLO) refresh-rate Quick Settings tile
- No bundled updater pointing at third-party servers
